# Privacy Policy

**Last updated: October 12, 2026**

## Overview

YouTube Analytics Automation is a private, owner-operated tool. It is used only by the owner of the YouTube channels that explicitly authorize it. It is not offered to the public as a service.

## Data accessed

With the channel owner's authorization, the application accesses YouTube channel and video metadata, YouTube Analytics reports, and YouTube Reporting API reports. This can include video identifiers, titles, thumbnail URLs, publication dates, duration, views, watch-time metrics, traffic-source metrics, subscriber gains and losses, thumbnail impressions, and impressions click-through rate.

The application does not request access to passwords, private messages, browsing history, or payment information.

## How data is used

Authorized data is used only to create private historical analytics, comparisons, and performance reports for channels controlled by the application owner. Data is not sold, used for advertising, or shared with unrelated third parties.

## Storage and security

Analytics output is stored in a private GitHub repository controlled by the channel owner. OAuth client credentials and refresh tokens are stored using GitHub Actions encrypted secrets and are not committed to source control. This public repository contains no credentials or channel analytics.

## Retention, corrections, and deletion

Historical authorized analytics may be retained for longitudinal channel analysis while authorization remains active. The application periodically verifies continued authorization and refreshes relevant metadata. If authorization is revoked or deletion is requested, associated stored data will be deleted as required by applicable Google and YouTube API policies.

## Sharing

Authorized YouTube data is not disclosed to third parties except infrastructure providers needed to operate the private automation, such as Google APIs and GitHub Actions.

## Your controls

Access can be revoked through the Google Account permissions page. The channel owner may also request deletion of stored data by contacting the address below.
