# Local Email Sender

Local Email Sender is a private, owner-operated desktop tool used by its owner to manage authorized Gmail sending, scheduled follow-ups, reply detection, and delivery-status checks.

The application is not offered as a public service and does not accept third-party users.

## What the application does

- Sends email only from Gmail accounts explicitly authorized by the owner.
- Uses Gmail API access to manage the owner's scheduled messages and detect relevant replies or delivery notices.
- Keeps sender queues, message history, and operational state on the owner's local computer.
- Uses deterministic safety checks to avoid duplicate sends and to respect suppression, reply, and bounce rules.

## Data handling

Gmail data is used only to operate the owner's local sender workflows. It is not sold, used for advertising, or shared with unrelated third parties.
