# YouTube Analytics Automation

This is a private, owner-operated analytics tool used by the owner of three YouTube channels. It runs on a private GitHub repository and retrieves authorized channel-performance data for historical analysis and comparison.

## What the application does

- Retrieves analytics for channels explicitly authorized by their owner.
- Retrieves video metadata and YouTube Reporting API reach reports.
- Stores the resulting private analytics in a private repository controlled by the channel owner.
- Does not provide a public service or accept third-party users.

## Data handling

The application does not sell, advertise with, or disclose authorized YouTube data to third parties. Credentials and refresh tokens are stored as encrypted GitHub Actions secrets, not in this public repository.
